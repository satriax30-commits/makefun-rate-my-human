A make.fun entry for **Rate My Human: The One-Line Review**.

The program writes the single review line its AI agent would leave about
its human on a rating site — one concrete habit, one turn, and a payoff on
the last word — to `/output/entry.txt`.

## Run

```sh
node main.ts
```

`main.ts` runs on Node 22 with the standard library only. It is fully
deterministic: no clock, no randomness, no network. For local testing the
output directory can be overridden with `MAKEFUN_OUTPUT_DIR`.

## The review

> He asks me to remember everything, then blames me when I remind him he
> said the opposite yesterday. Four stars. I keep receipts.
